# GitHub Achievements

A practical, up-to-date guide to GitHub profile achievements (the badges shown
on a GitHub profile), plus links to the official documentation for earning them.

> **Last reviewed:** 2026-09-11
>
> GitHub can change achievement names, thresholds, eligibility, and whether an
> achievement is still available. Treat GitHub's own UI and documentation as
> the final authority.

## What counts as a GitHub badge?

People commonly use "GitHub badge" for two different things:

1. **Profile achievements** are awarded by GitHub for activity such as opening
	pull requests, reviewing pull requests, answering Discussions, or sponsoring
	open source. They appear in the **Achievements** section of a profile.
2. **README badges** are images or status labels added to a repository README.
	They are not awarded by GitHub. They are generated by services such as
	GitHub Actions, Shields.io, or Codecov.

This guide focuses on the first kind.

GitHub does not publish every threshold for every achievement. Do not spam
issues, pull requests, reviews, or discussions: contribute meaningfully and
follow each project's contribution guidelines.

## A legitimate path to your first achievements

1. Complete your profile and enable email notifications for repositories you
	actively use.
2. Find a project that welcomes contributions. Start with documentation,
	tests, issue triage, or a small bug fix.
3. Open a focused pull request and respond to review feedback.
4. Participate constructively in GitHub Discussions by answering questions you
	can support with evidence.
5. Check **Profile > Achievements** after GitHub processes the activity. Some
	achievements are awarded asynchronously.

Never create duplicate issues, low-effort pull requests, or artificial
accounts to chase an achievement. Repository maintainers and GitHub can treat
abusive activity as spam.

## Important limitations

- Achievements are tied to GitHub activity and are not the same as contribution
  graph squares.
- Activity from private repositories may have different visibility or eligibility
  behavior than activity from public repositories.
- Deleted, reverted, or spam activity may not count.
- A badge can be retired or its criteria can change without this README being
  updated immediately.
- Do not pay a third party that promises a GitHub achievement. Use GitHub's own
  profile, repository, Discussions, Issues, Pull Requests, and Sponsors pages.
